# 📊 OpenDota API

OpenDota API is a **client wrapper** for Dota 2 statistics: **matches**, **players**, **heroes**, and **parsed replays**. It handles pagination and response **caching**.

## ✨ Key Features

- 🆔 **Match lookup** by ID
- 👤 **Player and hero stats**
- 🎞️ **Parsed replay** endpoints
- 📄 **Pagination** helpers
- 💾 **Response cache**
- 🧾 **Typed models**
- 🔁 **Retry with backoff**
- 📈 **Rate readout**

## 🚀 Why Choose OpenDota API?

Raw endpoints return large nested objects and paged lists. The wrapper flattens paging and caches repeats, so a dashboard does not spam the service.

Parsed replay fields are surfaced directly instead of buried.

## 🎮 Why Use It?

- **Query matches** by ID
- **Pull player stats**
- **Read parsed data**
- **Cache repeats**
- **Page results** safely
